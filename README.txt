FLYWOOOKI STUDIO 0.3 PWA – PROTOTYP

Co zawiera:
- bazę danych aplikacji w localStorage na danym urządzeniu/przeglądarce
- dashboard, ewidencję szpul, faktur, rozchodu zewnętrznego, katalogu i historii (funkcje prototypu 0.2.1)
- responsywne poprawki dotykowe dla iPhone/iPad
- manifest PWA, ikonę i service worker (cache aplikacji/offline shell)
- przycisk „Instalacja PWA” z instrukcją dla iOS
- eksport i import kopii JSON

INSTALACJA NA IPHONE/IPAD:
1. Aplikacja musi być opublikowana pod adresem HTTPS (np. hosting statyczny).
2. Otwórz ten adres w Safari.
3. Safari: Udostępnij -> Dodaj do ekranu początkowego.
4. Uruchamiaj aplikację z dodanej ikony.

WAŻNE:
- Ten ZIP sam w sobie nie jest instalatorem; to pakiet źródłowy PWA do hostowania.
- Dane magazynu są lokalne dla urządzenia/przeglądarki. Nie ma jeszcze automatycznej synchronizacji iCloud między urządzeniami.
- Aby przenosić dane między urządzeniami, użyj Eksport kopii, a następnie Import kopii na drugim urządzeniu. Eksport/import pliku JSON można przeprowadzić z użyciem aplikacji Pliki/iCloud Drive.
- Nie używaj tej wersji jako jedynej kopii danych. Regularnie eksportuj backup.
